# Tiki v1.0.0 — Greenfield Onboarding

The 1.0 milestone: point Tiki at a **blank folder** and go from nothing to a working,
GitHub-wired project with a scoped backlog — without leaving the app.

## Epic A — Greenfield skeleton (blank folder → working project)
- **#283** New `init_tiki_project` Tauri command + a git-write layer (`git_init -b main`,
  `git_add_remote`, `git_commit_all`, `git_remote_get`, all via `hidden_command`). Composes the
  framework install with a **guarded** state seed (only-if-absent — never the destructive
  overwrite path) and a starter `.gitignore` that commits the durable `.tiki/` record and ignores
  the transient bits. Best-effort initial commit (a missing git identity warns, never aborts).
- **#284** A greenfield **readiness checklist** in Settings (framework / state / git repo / remote /
  gh auth / .gitignore), each row with its own **Fix** action. New `check_greenfield_readiness`
  backend that reports cleanly on a blank folder.
- **#285** **Add Project** no longer dead-ends on a folder without `.tiki/` — it offers
  "Initialize Tiki here" and sets the project up in place.
- **#287** Guided **"Create GitHub repo"** + wire origin: `gh repo create --source=. --remote=origin`
  with an auth-first guard and an existing-remote short-circuit (terminal-assisted).

## Epic B — Greenfield scoping (`/tiki:scaffold`)
- **#289 / #290 / #291** A new conversational command that **interviews** a brand-new project into a
  project brief, decomposes a **small spine** of epics → first-wave issues (with success criteria and
  dependency edges), stages it locally for review, and — only on explicit confirm — **pushes it to
  GitHub** as real issues with rendering dependency edges. The push is idempotent across partial
  failures (incremental id-map + pre-create existence probe), and groups the issues into a release so
  the dependency graph renders them.

## Epic C — Project docs
- **#294** A new `/tiki:claudemd` command that generates a project **`CLAUDE.md` from the scaffold
  brief** — no re-interviewing; aspirational structure is marked `TODO:` rather than invented.
